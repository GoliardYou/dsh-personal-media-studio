01

设计原则

三条约束，决定所有取舍的优先级。

P1

内容在前，界面退后

作者的原话是主角。界面用低饱和的中性色和克制的边框，把注意力让给文字本身；只有主操作允许使用品牌绿。

P2

令牌唯一来源

颜色、字号、间距、圆角只能引用令牌。新增一个视觉值之前，先问是否已有令牌能表达同一意图。

P3

屏幕上可信，导出后一致

界面跟随宿主浅深色，出图画布则完全隔离。作者在深色编辑器里排的版，导出 PNG 必须和浅色下完全一致。

02

色彩系统

三层结构：Primitive 原始色阶 → Semantic 语义令牌 → Canvas 出图专用。

主色 Green 提炼自产品既有的头像线稿绿，不是另造一套。所有文字色均已按 WCAG 2.1 AA 实测校验，下方「对比度自检」为脚本计算的真实值。

2.1　品牌主色阶 Green

2.2　强调色阶 Gold

对白底仅 2.26:1，禁止用作文字或图标颜色。只允许出现在装饰线、画布高亮和品牌标识中。

2.3　中性色阶 Neutral

带极轻绿灰调，与画布纸白 #F5F6F0 同族，避免冷灰造成的割裂感。

2.4　聚焦纸感色阶 Paper

只服务于聚焦编辑台，不替换品牌 Green。三级墨色对米纸底全部达到 AA，金色依旧禁止作文字。

2.5　语义令牌

业务样式只允许使用这一层。每个语义令牌优先消费 DSH 宿主的 --dsw-alias-*， 宿主未提供时才落回品牌原始值 —— 这保证插件在宿主切换明暗主题时自动跟随。

令牌用途取值来源

2.6　对比度自检

脚本实测值，非估算。AA = 正文合格（≥4.5:1），AA Large = 仅限 ≥18.66px 粗体或 ≥24px，FAIL = 禁止用于前景。

你不需要更多选题，你需要更少犹豫

大部分人卡在选题上的时候，其实不是没东西可写，而是同时有三四个方向在争抢注意力。 真正的瓶颈从来不是素材量，而是做决定的成本。

4.2　圆角

05

动效

三条时长 + 两条曲线。超出集合的时长视为违规。

曲线cubic-bezier

6.5　分段控件

表达「当前位置」而非「主操作」。视觉权重刻意低于按钮 —— 导航不该抢主操作的注意力。 用在两处：全局阶段切换（选题 / 改稿 / 渲染）与页内视图切换（看板 / 问答池、写作 / 阅读、大纲 / 建议 / 版本）。

带计数的阶段导航aria-selected 驱动选中态
无计数的视图切换比阶段导航更轻

单行工具栏 pms-toolbar 承载品牌标记、分段导航、上下文说明与阶段主操作，固定 56px。 原先的产品名大标题与独立导航条共占约 150px，压缩后渲染阶段的编辑器高度增加约 94px。

07

无障碍

WCAG 2.1 AA 是底线，不是加分项。

要求实现方式状态
文字对比度所有正文色 ≥4.5:1，已脚本实测；三级文字调至 #707468（4.53:1）达标
键盘可达全部交互元素可 Tab 到达，统一 :focus-visible 焦点环，鼠标点击不显示达标
触控目标@media (pointer: coarse) 下自动补至 44×44px达标
动效偏好尊重 prefers-reduced-motion，全局降为 0.01ms达标
语义结构原生 button / label，不滥用 div；图标按钮带 aria-label达标
文字缩放全部使用相对字号体系，200% 缩放下布局不溢出达标
状态不只靠颜色徽标同时使用文字标签，不只依赖红绿区分达标
08

双主题隔离

界面跟随宿主，画布永不跟随。

这是本产品最容易出错的地方。界面令牌（--pms-surface-* 等）优先取宿主的 --dsw-alias-*，会随宿主明暗变化；而出图令牌（--pms-canvas-*） 是固定值，因为导出的 PNG 必须与宿主主题无关。若画面误用界面令牌，用户在深色模式下排的版， 导出后会得到一张深色底的图 —— 这是不可接受的。

出图画布样张固定纸白，不随主题

令牌分工命名即约束
--pms-surface-*界面表面，跟随宿主
--pms-text-*界面文字，跟随宿主
--pms-primary主操作色，跟随宿主

规则：.pms-page 及其后代只允许使用 --pms-canvas-*。

09

落地检查

提交界面改动前的自查，逐条过。

  1. 新写的 CSS 里没有十六进制色值 —— 全部走 var(--pms-*)。
  2. 没有裸 px 圆角与字号，圆角只用 6 档刻度，字号只用字阶。
  3. 所有间距是 4 的倍数，且优先复用 --pms-gap-* / --pms-pad-* 语义令牌。
  4. 新增颜色前先确认语义令牌是否已能表达同一意图，不新增冗余色。
  5. 交互元素有 hover / active / disabled / focus-visible 四态。
  6. 纯图标按钮带 aria-label，表单控件有对应 label。
  7. 画布区域没有误用界面令牌（会破坏导出稳定性）。
  8. 在深色模式下过一遍：文字可读、边框可见、阴影不糊。
  9. 用 Tab 键走完全流程，焦点环始终可见。
  10. 改动令牌后回本页确认色板与对比度表仍符合预期。
